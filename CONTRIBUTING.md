# Contributing to Historic Shortwave

Corrections and new recordings are welcome. All changes are reviewed before
they are merged.

## Suggesting a recording

Open an issue titled "Recording: <station>, <frequency> kHz, <date>" with:

| Field | Example |
|---|---|
| Station, as identified on the recording | HONDURAS HRRI, Sani R. |
| Frequency (kHz) | 4920 |
| Date of recording | 1974-03-12 (or "circa 1974") |
| Time (UTC) | 0315 |
| Audio URL (direct file) | https://archive.org/download/... |
| Source page | https://archive.org/details/... |
| Recordist, if the source names one | |
| License or rights statement shown by the source | CC BY-NC 3.0 |
| How the frequency and date are known | Announced on air; uploader's notes |

Only link to recordings. Do not upload audio files to this repository.
Recordings must be publicly hosted by their source, and we can add only those
whose source states terms that permit this use.

## Corrections

If a frequency, date, station identification or credit is wrong, open an issue
with the record and your evidence: a period listing (WRTH, FBIS, a club
bulletin), the announcement on the recording, or the source page.

## Code changes

1. Fork the repository and work on a branch.
2. Run the relevant tests in `tools/` (`test-*.py`, `test-*.cjs`).
3. Open a pull request that says what changed and why.

Do not edit the release folders (`release/`) by hand. They are generated by the
build scripts in `tools/`.
