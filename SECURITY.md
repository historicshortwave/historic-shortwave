# Security policy

Historic Shortwave is a static website. It has no accounts, no server code and no forms, and it collects no information from visitors. The page plays recordings only from archive.org, under a Content Security Policy that blocks other sources.

## Reporting a problem

If you find a security problem in the site or in this repository, please report it privately rather than in a public issue:

- Email historicshortwave@gmail.com with "Security" in the subject line, or
- Use **Report a vulnerability** on this repository's **Security** tab, if it is shown.

Please describe the problem, the page or file involved, and how to reproduce it. You will get a reply as soon as the report has been reviewed.

## Scope

In scope: the published site at https://historicshortwave.org/ and the code in this repository.

Out of scope: the recordings themselves and the services that host them, chiefly the Internet Archive. Report problems with those to their hosts.
